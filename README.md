# IT Help Desk Ticketing Platform

A simple full-stack help desk application built for portfolio demonstration of IT support / service desk skills.

## Features
- User registration and login
- Raise and track personal support tickets
- Admin dashboard to view, update status, and add resolution notes for all tickets
- Category-based "Suggest Fix" helper for common issues
- Clean, professional interface

## Admin Login

## Setup and Run
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the application:
   ```
   python app.py
   ```
3. Open http://localhost:5000 in your browser.

## Portfolio Note
This project demonstrates ticket lifecycle management, user vs admin roles, and basic troubleshooting workflows relevant to IT support and service desk positions.
